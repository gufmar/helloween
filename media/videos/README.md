# Video clips (local only)

Drop `.mp4` / `.webm` files here (15–30 s is a good length). Binaries are gitignored.

In the control UI under **Videos**:
1. **Refresh files**
2. Pick a file and **+ Clip**
3. Position the purple rectangle on the facade (Calibration on)
4. **▶** in the list plays one clip; checkbox selects clips for **Play sequence** (gap between clips)
5. **Load speakers**, then pick an output per clip (Chrome/Edge, `setSinkId`)

Tips:
- Prefer dark / black backgrounds so the wall reads cleanly through the mask.
- Keep resolution moderate (e.g. 720p–1080p); clips scale into the placed rect.
- Audio on the projector follows the clip speaker when the projection window has unlocked audio.
